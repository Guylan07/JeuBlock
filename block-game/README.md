# Block Game

Un jeu simple où vous pouvez choisir de bloquer des personnes dans vos discussions.

## Description

Block Game est une application web qui simule une interface de messagerie avec des contacts fictifs. Chaque conversation contient un message non lu de la part d'un NPC (personnage non-joueur). Vous pouvez décider de lire le message et de bloquer la personne ou de continuer la conversation.

## Installation

1. Clonez ce dépôt :
```
git clone <votre-url-de-repo>
cd block-game
```

2. Installez les dépendances :
```
npm install
```

3. Lancez l'application en mode développement :
```
npm start
```

L'application sera accessible à l'adresse [http://localhost:3000](http://localhost:3000) dans votre navigateur.

## Déploiement sur Vercel

1. Créez un compte sur [Vercel](https://vercel.com/) si vous n'en avez pas déjà un.

2. Installez l'outil CLI de Vercel :
```
npm install -g vercel
```

3. Connectez-vous à votre compte Vercel depuis le terminal :
```
vercel login
```

4. Déployez votre application :
```
vercel
```

Suivez les instructions pour finaliser le déploiement.

## Fonctionnalités

- Liste de conversations avec des contacts fictifs
- Messages non lus
- Possibilité de bloquer des contacts
- Interface utilisateur simple et intuitive
